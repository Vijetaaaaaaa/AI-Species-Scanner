# 🛰️ AI Species Identification Portal

Can AI tell whether you're secretly a penguin?

This project uses Google's Teachable Machine and TensorFlow.js to perform real-time image classification through your webcam. It identifies whether the detected subject is a human or a penguin and displays a fun AI-generated species report.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- TensorFlow.js
- Google Teachable Machine

## Features

- 🎥 Live webcam classification
- 🐧 Penguin vs Human detection
- 🤖 Interactive AI species scanner UI
- 📊 Confidence score display
- 😂 Random humorous scan verdicts
- ⚡ Runs entirely in the browser
